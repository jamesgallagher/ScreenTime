## 1. Project context

Screen Time is a self-hosted parental screen-time limiter for one family. Kid devices (Android phone/tablet, Windows 11 PCs) enforce daily time limits locally; a TypeScript server on Docker holds the shared record; parents use a web app and an Android parent app. The whole system lives in one monorepo. The full specification is `docs/SPEC.md`; the order of work is `docs/BUILD-PLAN.md`. Repository rules for coding agents are in `AGENTS.md` at the repo root: read it first.

This is the very first code card. The repository currently contains only documentation (`README.md`, `AGENTS.md`, `docs/`).

## 2. Goal

After this card the repo has the final top-level folder layout, a working **pnpm workspace** for the TypeScript parts, a shared schema package `@screentime/schemas` with one Zod schema, and a minimal **Hono** server `@screentime/server` that answers `GET /health`. `pnpm install`, `pnpm build`, `pnpm typecheck` and `pnpm test` all pass on James's Windows PC.

### 5.11 `packages/schemas/src/health.ts`

```ts
import { z } from 'zod';

/** Response body of GET /health. */
export const HealthResponse = z.object({
  status: z.literal('ok'),
  service: z.string().min(1),
  time: z.iso.datetime(),
});

export type HealthResponse = z.infer<typeof HealthResponse>;
```

Note: `z.iso.datetime()` is the Zod 4 API. Do not change it to `z.string().datetime()`.

import { HealthResponse } from '../src/index.js';

describe('HealthResponse', () => {
  it('accepts a valid body', () => {
    const body = { status: 'ok', service: 'screentime-server', time: '2026-10-22T09:00:00.000Z' };
    expect(HealthResponse.parse(body)).toEqual(body);
  });

  it('rejects a wrong status', () => {
    const body = { status: 'down', service: 'screentime-server', time: '2026-10-22T09:00:00.000Z' };
    expect(HealthResponse.safeParse(body).success).toBe(false);
  });

  it('rejects a time that is not ISO 8601', () => {
    const body = { status: 'ok', service: 'screentime-server', time: 'yesterday' };
    expect(HealthResponse.safeParse(body).success).toBe(false);
  });
});

## 6. Detailed spec

`GET /health`

- Status `200`, header `Content-Type: application/json`.
- Body: `{ "status": "ok", "service": "screentime-server", "time": "<current UTC time, ISO 8601, e.g. 2026-10-22T09:00:00.000Z>" }`
- Any other path returns Hono's default `404`.

Server port comes from the `PORT` environment variable, default `8080`.

Root scripts:

| Command | Does |
|---|---|
| `pnpm build` | builds `@screentime/schemas` then `@screentime/server` (pnpm runs them in dependency order) |
| `pnpm typecheck` | `tsc --noEmit` in each package |
| `pnpm test` | build, then Vitest in each package |
| `pnpm dev:server` | builds schemas, then runs the server with `tsx watch` |
