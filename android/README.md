# android

One Gradle project with two apps and shared modules, all Kotlin + Jetpack Compose:

- `app-kid/` kid enforcer app (Device Owner)
- `app-parent/` parent app
- `core-model/` generated API client and models
- `core-time/` time engine (must pass `test-vectors/`)
- `core-ui/` theme and shared components

Created by CARD-004. See docs/SPEC.md §12.1 and §16.2.
